核心功能

🎤

AI 语音润色

说完就润色：系统语音识别 → AI 润色 → 一键上屏。支持语气、风格、翻译、缩写等。

✨

魔法修改

选中文字，用语音或预设指令让 AI 改写：扩写、缩写、翻译、换语气，立刻替换原文。

📖

魔法书

管理你的魔法指令：固定、新增、编辑、删除、撤销。打造你的专属“改写词库”。

⌨️

全键盘 / 双拼

标准 QWERTY 布局，Rime 引擎驱动，支持拼音、双拼、模糊音，以及长按功能键快捷键。

🔢

T9 九宫格

单手输入：2-9 数字键拼音 + 长按候选字母 + Shift 切换纯数字，兼顾效率与便利。

🔤

英文 / 符号键盘

中英符号快速切换、数字键盘，满足邮箱、密码、公式等输入场景。

安装与使用

  1. 从 GitHub Releases 下载 Cesia-xxx-debug.apk（约 55MB，覆盖安装即可）。
  2. 安装后进入 系统设置 → 系统 → 语言和输入法 → 虚拟键盘，启用 Cesia。
  3. 再进入默认键盘，选择 Cesia。
  4. 打开任意输入框，即可使用全键盘、T9，以及录音润色和魔法修改。
  5. 在 Cesia 设置中可配置 API URL / Key、AI 模型、回复风格、开关模糊音、切换深浅主题。
